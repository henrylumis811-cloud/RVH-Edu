# RVH Edu V140 — Bulk marks learner search and list usability

- App version name: 1.2.0
- App version code: 106

## Changes
- Added search within the selected class roster on Bulk marks.
- Search matches learner names and enrollment IDs, case-insensitively.
- Added a clear-search control and a visible filtered-result count.
- Added a helpful empty state when no learners match the query.
- Kept entered marks, saved marks, and save operations scoped to the full selected roster so filtering does not exclude other learners from saving.
- Slightly tightened assessment-card padding and learner-row spacing to reclaim vertical space.
