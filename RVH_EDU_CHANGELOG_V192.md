# RVH Edu V192 — Ranked report cards and subject performance registers

- Individual report cards now show class position among complete learners in the same class/year/term/assessment section. Tied learners retain competition ranking. Incomplete learners are not counted as ranked.
- Class results exports (PDF, Excel and CSV) now include a subject performance analysis appendix/table: assessed and missing counts, coverage, average, pass rate, highest, lowest, AMGP and D/C/P/F distribution.
- Pass rate uses the assessment's saved pass threshold and assessed learners only. AMGP uses the assessment's saved grading scale and D/C/P/F weights 1/2/3/4. Legacy assessments use the current school grading configuration.
- Missing marks remain missing and are excluded from subject averages, pass rates and AMGP.
- Existing result ranking, mark values, database schema and stored academic records are unchanged.
